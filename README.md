# БАРАБАН — Telegram Mini App

Social-idle игра: крути 3D-барабан свайпами, копи очки, выживай в рулетке. MVP кор-луп по ТЗ v1.0.

## Что внутри

Один файл `index.html` без сборки и зависимостей:

- 3D-барабан — CSS 3D Transforms, 16 граней, динамическое цилиндрическое затенение
- Физика из ТЗ: трение, импульс свайпа, комбо, масса/смазка
- RUBBER-деформация: свайп-панч + скоростная деформация
- Инком, криты, монетки-частицы, speed-линии, генеративный звук (Web Audio)
- Рулетка с патронами по раундам и статом удачи
- Уровни (XP от свайпов) и улучшения 1 из 3 (пул из 6 типов)
- Экран выбывания с потерей очков партии
- Telegram Web App API: expand, haptic feedback, отключение вертикальных свайпов

Физика нормализована по dt — на 120 Гц экранах скорость игры та же, что на 60 Гц.

## Запуск локально

```bash
python3 -m http.server 4173
# открыть http://localhost:4173
```

Мышью свайпать тоже можно (pointer events).

## Деплой как Telegram Mini App

1. Задеплоить папку на Vercel / Cloudflare Pages (статика, нужен HTTPS).
2. В @BotFather: `/newbot` → затем `/newapp`, указать URL деплоя.
3. Открыть мини-апп через бота — авторизация, хаптика и фуллскрин подхватятся автоматически.
